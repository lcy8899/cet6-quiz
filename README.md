# 六级词汇答题软件（CET-6 Vocabulary Quiz）

一个**无需安装、无需联网**的六级词汇答题软件：显示英文单词，从 4 个中文释义选项中选出正确答案。

## 🚀 怎么使用

**双击 `index.html`** 用浏览器（Edge / Chrome 均可）打开即可开始答题，无需服务器、无需联网。

> 文件夹内只需保留 `index.html` 和 `data.js` 两个文件即可正常使用。

## 📚 词库说明

| 词库 | 词数 | 来源 |
|------|------|------|
| 六级真题核心词 | 1228 | 有道考神团队（大纲 + 历届真题词频筛选） |
| 新东方六级词汇 | 2345 | 新东方 |
| 六级英语词汇大纲 | 2078 | 教育部大学英语课程教学要求 |
| **合并去重后总计** | **3991** | |

数据来自 GitHub 开源词库 [kajweb/dict](https://github.com/kajweb/dict)（有道词典正版导出数据），每词包含音标、中文释义、部分含真题例句。

## 🎯 功能

- **答题模式**：英文单词 + 音标 → 4 选 1 中文释义；60% 概率用同首字母词做干扰项，提高辨析难度
- **智能出题**：可选词库范围（全部 / 真题核心词）、题量（10/20/50/100）、随机或按字母顺序（顺序模式自动从上次学到的地方继续）
- **只练未掌握**：跳过已掌握的词，专注生词
- **错题本**：答错自动收录；重练答对一次即自动移出
- **掌握判定**：连续答对 2 次记为「已掌握」，首页显示总进度
- **学习报告**：每组结束显示正确率环形图、用时、错词列表，可一键重练错题
- **词库浏览**：支持英文单词 / 中文释义双向搜索，按核心词、已掌握、错题筛选
- **单词发音**：点击单词或 🔊 朗读（使用浏览器内置语音合成）
- **进度保存**：学习记录保存在浏览器本地（localStorage），换浏览器或清除浏览数据后需重新开始
- **键盘快捷键**：答题时按 `1`-`4` 选择答案，`回车` / `空格` 下一题

## 📁 文件结构

```
cet6-quiz/
├── index.html   # 软件主程序（双击打开这个）
├── data.js      # 词汇数据（3991 词，勿删）
├── process.js   # 词库生成脚本（从 raw/ 目录的原始数据生成 data.js）
├── README.md    # 本说明
└── raw/         # 原始词库数据（仅重新生成 data.js 时需要）
```

## 🔄 重新生成词库（可选）

如需更新词库：把 [kajweb/dict](https://github.com/kajweb/dict) 仓库 `book/` 下的 `CET6_2.zip`、`CET6_3.zip`、`CET6luan_1.zip` 下载解压到 `raw/` 目录（得到三个同名 `.json`），然后运行：

```
node process.js
```
